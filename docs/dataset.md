# Dataset

This repository does **not** redistribute Wi-PER81.

Wi-PER81 contains radio-signal captures from 81 identities, with two acquisition sessions per identity. Each capture contains 1,000 packets and 52 data subcarriers, and the public release includes CSI values, amplitude representations, and signal-magnitude heatmaps.

- Dataset DOI: https://doi.org/10.6084/m9.figshare.26984497
- Dataset/code record referenced by the paper: https://doi.org/10.6084/m9.figshare.29477087
- Paper: Cascio, M., Cinque, L., Distante, D., Foresti, G. L., & Fagioli, A. *A Benchmark Dataset for Radio Signal Image-based Person Re-Identification*. Scientific Data 12, 1522 (2025). https://doi.org/10.1038/s41597-025-05804-0

Follow the dataset's own license and citation requirements when downloading or redistributing it.
