01 / THE IDEA

You can't see Wi-Fi.
But Wi-Fi can reveal patterns.

Wireless signals travel through spaces, reflect off objects, and change around the human body. Those subtle differences can be measured. The research question: can a model learn to associate the resulting patterns with a known individual?

STEP 01 — TRANSMIT

Wi-Fi travels.

Radio waves leave a transmitter and pass through an environment, even when no camera is involved.

STEP 02 — INTERACT

People change the waves.

A human body alters the signal's measured strength across different frequencies and moments in time.

STEP 03 — MATCH

AI finds similarities.

A model learns a compact signature and searches for the closest match among identities represented in training.

02 / WHAT THE MODEL SEES

Not a photograph. A pattern of frequencies.

We trained on numerical CSI amplitude windows — 100 packets × 52 subcarriers — rather than pictures of people.

03 / THE KEY DISCOVERY

A surprising lesson:
not all data should be treated like images.

CONTROLLED EXPERIMENT · M2 vs M3

Respect the physics of the signal, and the model performs far better.

We compared photo-style transformations, such as flipping a signal map, with physically meaningful variations like gain drift, noise and interference. Everything else in this experimental comparison was kept consistent.

Signal-aware augmentation simulates plausible changes in measurement — such as transmission gain changes, narrowband interference, and background noise — while keeping the ordered frequencies meaningful.

05 / FOR THE CURIOUS

Want to know how we built it?

Below is the actual modeling pipeline, unpacked in plain language first and technical language second. Each step links back to the research question: can we learn identity-related patterns without destroying their physical meaning?

CSI windows→Pairs→Neural model→Signature→Match

For source code, evaluation scripts, complete metrics, and experiment documentation, see the GitHub repository ↗.

01Prepare a Wi-Fi measurement+

Each sample is a numerical matrix of 100 consecutive packets and 52 ordered subcarriers. The pipeline sanitizes measurements and normalizes using the training data only. These values describe radio-channel amplitude, not an image of a person.

02Learn which signatures belong together+

A Siamese learning setup presents examples from matching and non-matching identities. Training pairs are regenerated each epoch so that the model sees new comparisons instead of memorizing a fixed list.

03Augment the data without breaking its meaning+

SubCarrierAug varies signal gain, drops and interpolates a few subcarriers, resamples along time, adds plausible noise, and shifts the window within a capture. A separate VisionAug control tests photo-inspired flips and crops.

04Focus on useful frequencies and moments+

A convolutional encoder with dual-axis attention highlights informative frequency channels and packet positions. The result is a 128-dimensional identity embedding that can be compared using cosine similarity.

05Evaluate the matches honestly+

Model development uses session A; held-out session B supplies probe/gallery windows. Six controlled configurations were compared across three random seeds, with bootstrap 95% confidence intervals. Rank-1, Rank-5, mAP and Macro-F1 are reported in the repository.
